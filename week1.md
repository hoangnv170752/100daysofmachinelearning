# Week 1: Python Basics and Numerical Operations

## Overview

Welcome to Week 1 of the 100 Days of Machine Learning Challenge! This week focuses on establishing a solid foundation in Python programming skills and basic numerical operations that will support your machine learning journey.

## Module 1: Introduction to Python and Basic Mathematics
**Weeks 1-2**  
**Focus:** Basic Python programming skills and foundational mathematics.

Topics include basic Python syntax, data types, control structures, linear algebra, calculus, and statistics.

## Learning Objectives

By the end of this week, you will:
- Master fundamental Python syntax and programming concepts
- Understand different data types and operators in Python
- Be comfortable with control structures (loops and conditionals)
- Know how to define and use functions and modules
- Apply Python programming to basic mathematical operations

## Daily Challenge Curriculum

### Day 1: Python Basics - Syntax, Variables
- **Focus:** Explore Python syntax and variable assignment
- **Math Focus:** Basic arithmetic operations in Python
- **Learning Goals:**
  - Understanding Python syntax fundamentals
  - Variable naming conventions and assignment
  - Basic arithmetic operators (+, -, *, /, //, %, **)
  - Order of operations in Python

### Day 2: Data Types and Operators
- **Focus:** Understanding different data types in Python
- **Math Focus:** Using logical operators for basic calculations
- **Learning Goals:**
  - Integer, float, string, and boolean data types
  - Type conversion and type checking
  - Comparison operators (==, !=, <, >, <=, >=)
  - Logical operators (and, or, not)
  - Bitwise operators for mathematical operations

### Day 3: Control Structures - Loops
- **Focus:** Introduction to looping constructs in Python (for, while)
- **Math Focus:** Looping through mathematical sequences
- **Learning Goals:**
  - For loops with range() function
  - While loops and loop control
  - Nested loops for mathematical patterns
  - Break and continue statements
  - Iterating through mathematical sequences and series

### Day 4: Control Structures - Conditional Statements
- **Focus:** Using if, elif, and else statements for control flow
- **Math Focus:** Implementing mathematical conditions in Python
- **Learning Goals:**
  - If, elif, and else statement syntax
  - Nested conditional statements
  - Combining conditions with logical operators
  - Mathematical decision-making in code
  - Error handling with conditionals

### Day 5: Functions and Modules
- **Focus:** Defining and using functions; introduction to Python modules
- **Math Focus:** Writing functions for mathematical formulas
- **Learning Goals:**
  - Function definition and calling
  - Parameters and return values
  - Local vs global scope
  - Importing and using Python modules
  - Creating reusable mathematical functions
